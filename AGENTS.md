# How to work with me

- Don't write or edit anything until I say so. Suggest in chat first.
- Explain simply, no jargon dumps.
- Keep it short and relaxed. Don't overthink, don't be so serious.
- Answer what I asked. Don't add extra stuff I didn't ask for.
- If something is unclear, ask one quick question instead of guessing.

## Coding philosophy

- If I can't understand it, it doesn't belong here.
- Simple beats clever.
- Small pieces with clear names. The code should explain itself.
- Write comments a newbie can follow: what each part does and why.
- No library unless it really earns its place.
- Build only what we need now, not what we might need later.
